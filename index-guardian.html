Product Detail

Index Guardian

設計書管理、機器管理、EOSL管理、課題管理を一つの画面群で扱える、 インフラ運用向けの業務管理Webアプリケーションです。

Overview

運用情報を、追いやすい形にまとめる

Index Guardian は、日々更新される設計情報、管理機器、EOSL期限、課題の状態を まとめて見渡せるようにした実務アプリです。

情報の保管先が散らばっていても、画面単位で役割が分かれているため、 今どの情報を見ればよいかを迷いにくくなります。

インストーラーをダウンロード 導入を相談する 一覧へ戻る

Feature 1

設計書管理

設計書の登録、検索、編集、テンプレート管理に対応し、関連資料もまとめて追いやすくします。

Feature 2

機器管理 / EOSL管理

管理機器の一覧化とEOSL期限の把握を同じ流れで行えます。更改計画の整理にもつなげやすい構成です。

Feature 3

課題管理

インフラ運用上の課題をステータス付きで整理し、未対応事項をチームで共有しやすくします。

Feature 4

管理者向け機能

ユーザー権限、通知設定、バックアップ、監査ログなど、継続運用に必要な管理機能を備えています。

Role

アクセス権限

管理者 設定変更、ユーザー管理、バックアップ、システム運用に関わる機能を扱えます。
一般ユーザー 設計書、機器管理、課題管理など、日常業務に必要な画面を利用できます。

Benefit

期待できる効果

  • 管理情報の置き場所を絞りやすくなる
  • EOSLや未対応課題の見落としを減らせる
  • 少人数でも引き継ぎしやすい状態を作れる
  • 日常運用の見通しと説明材料を揃えやすい
